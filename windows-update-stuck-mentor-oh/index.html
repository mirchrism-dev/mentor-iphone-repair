If It’s Stuck on the Updating Screen

1

Give it time

Large updates can sit at one percentage for a long time, especially on older PCs with hard drives. Wait at least an hour or two with the charger plugged in and the drive light still blinking.

2

Restart only if it’s truly frozen

If nothing has changed for several hours and there’s no drive activity, hold the power button to shut down, then start it again. Windows will usually try again or roll back.

3

Let “Undoing changes” finish

If it says it’s undoing changes, don’t turn it off. Let it get back to the desktop before trying anything else.

Back up important files before trying fixes on a PC that has trouble updating. See our computer backup guide.

If the Same Update Keeps Failing

Run the troubleshooter

On Windows 11, go to Settings, System, Troubleshoot, Other troubleshooters, then run Windows Update. On Windows 10, it’s under Update & Security, Troubleshoot.

Free up space

Updates need room to download and unpack. If the drive is nearly full, clear space first. See computer storage full.

Unplug extras

Disconnect USB drives, docks, and printers you don’t need during the update. Odd hardware sometimes blocks an install.

Look up the error code

Note the code shown in Update history (like 0x800f0922) and search it on Microsoft’s support site, which lists fixes for specific codes.

Pause, then retry

Pausing updates for a day and resuming can clear a stuck download.

Windows Update FAQs (Mentor, OH)

How long should a Windows update take?

Small monthly updates often take a few minutes to half an hour. Big feature updates can take an hour or more, especially on older PCs with hard drives.

Is it safe to turn off my PC during an update?

Avoid it if you can. Only force a shutdown if the screen hasn’t changed and the drive light hasn’t blinked for several hours.

Why does my PC say “Undoing changes” every time?

The update failed partway, and Windows is rolling back to keep the PC working. Low disk space, damaged system files, or a driver conflict are common causes.

Can I just skip Windows updates?

You can pause them for a while, but skipping them for good leaves the PC open to security problems. It’s better to fix what’s blocking them.

Will I lose my files if you fix it?

Fixing an update problem usually doesn’t touch your files, but we always recommend a backup first, and we’ll tell you before doing anything that could affect your data. Call (440) 525-5705 to ask.
