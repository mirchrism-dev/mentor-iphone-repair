Computer Storage Full? Here’s Where the Space Went

A computer that’s out of space gets slow, won’t install updates, and sometimes can’t save files at all. Usually the space is going to a few big things you can find and clean up in an afternoon. Where the Space Usually Goes

Photos and videos

Phone photo libraries synced to the computer, and video files, are often the biggest single chunk.

The Downloads folder

Old installers, PDFs, and duplicate downloads pile up for years without anyone noticing.

Old phone backups

iPhone backups saved to a computer can take up a lot of room, especially if there are several old ones.

Programs you no longer use

Games, trial software, and old apps can each take up several gigabytes.

Safe Ways to Free Up Space

1

See what’s using it

On Windows, open Settings, then System, then Storage. On a Mac, open System Settings, then General, then Storage.

2

Empty the Recycle Bin or Trash

Deleted files still take up space until the bin or trash is emptied.

3

Clean out Downloads

Sort by size and remove installers and files you already have elsewhere.

4

Uninstall programs you don’t use

Use the Windows app list or drag unused Mac apps to the Trash.

5

Move photos and videos

Copy them to an external drive or cloud storage, check that they opened fine there, then remove them from the computer.

Before you move or delete anything important, make sure it’s backed up. See how to back up your computer.

What Not to Delete

  • Folders inside Windows or System on a PC, or the System and Library folders on a Mac
  • Program files you don’t recognize, since deleting them by hand can break software
  • Your only copy of photos or documents, even if you think you have them somewhere else

Computer Storage Full FAQs (Mentor, OH)

How much free space should my computer have?

Leaving a healthy amount free helps updates install and keeps the computer running smoothly. If you’re regularly seeing low-space warnings, it’s time to clean up or upgrade.

Is it safe to use a disk cleanup program?

The cleanup tools built into Windows and macOS are generally safe. Be careful with third-party cleaner apps, especially ones that show scary warnings or ask for payment.

Why is my computer still full after deleting files?

The Recycle Bin or Trash may still hold them, or the space may be taken by something else, like old phone backups or a sync folder. The storage settings screen shows the breakdown.

Can you move my files to a bigger drive?

Yes. With an SSD upgrade we can move your existing files, programs, and settings over, so the computer works the way you’re used to.
