Computer Turns On — But Windows Won’t Load?

Your PC or laptop powers on, you see the maker’s logo, and then it hangs on spinning dots, drops into “Preparing Automatic Repair,” or restarts over and over. That’s a startup problem, not a dead computer. It can come from an interrupted update, a corrupted system file, or a hard drive or SSD that’s starting to fail. The most important thing is not to make the files on that drive harder to recover. Here’s what’s safe to try and when to bring it to Mentor iPhone and Computer at 7745 Mentor Ave, Mentor, OH 44060.

What You Might Be Seeing

“Preparing Automatic Repair” loop

Windows tries to fix itself, fails, and restarts into the same screen. Often caused by a damaged update or system files.

Stuck on spinning dots or the logo

The computer may be waiting on a slow or failing drive, or an update that never finished.

“No bootable device” or “boot device not found”

The computer can’t see the drive Windows lives on. That can be a setting, a loose connection, or a drive that’s failing.

Restarts right after the logo

Can be software, but also RAM, overheating, or a failing drive. A blue screen with an error code is a separate clue, see blue screen errors.

Safe Things to Try First

1

Unplug extra devices

Remove USB drives, external hard drives, SD cards, and docks. A computer sometimes tries to boot from the wrong device.

2

Let one update attempt finish

If the screen says it’s working on updates, give it a good while on the charger before forcing it off. Pulling power mid-update can make things worse.

3

Try a full shutdown and restart

Hold the power button until it turns off, wait a minute, then start it again once. If it loops the same way two or three times, stop there.

4

Write down any message or code

A photo of the error screen helps us a lot and saves diagnosis time.

Protect Your Files Before Anything Drastic

  • Avoid “Reset this PC” or reinstalling Windows if you have photos or documents you haven’t backed up. Some reset options remove your files
  • If you hear clicking, grinding, or the computer keeps freezing on the same spot, the drive may be failing. Repeated restarts can make that worse
  • We can check the drive’s health and, when the drive is readable, help get your files off before any repair. See computer data recovery
  • If the old drive is the problem, a faster SSD can be part of the fix. See SSD upgrade

Windows Won’t Start FAQs (Mentor, OH)

Why does my computer say “Preparing Automatic Repair” every time?

Windows detected a startup problem and is trying to fix it. When it can’t, it loops. Common causes are an interrupted update, corrupted system files, or a drive that’s starting to fail.

Will fixing it erase my files?

Not necessarily. Many startup problems can be repaired without wiping anything. The risky moves are resets and reinstalls done before your files are backed up, which is why we check first.

Is it my hard drive?

Sometimes. Slow startups that got worse over time, clicking noises, or a “no bootable device” message all point toward the drive. We test it before recommending a fix.
