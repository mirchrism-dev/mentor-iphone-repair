New Computer Setup FAQs (Mentor, OH)

Can you move everything from my old computer to my new one?

We can move your personal files, like documents, photos, music, and desktop items, and help with bookmarks and email. Programs usually have to be reinstalled on the new computer rather than copied, so bring license keys or account logins for any paid software.

Can you move files from a Windows PC to a Mac, or the other way?

Usually yes for files like photos and documents. Some programs only run on one system, so we’ll let you know if something you use won’t work on the new computer.

What should I do with my old computer?

Keep it until you’ve checked that everything you need is on the new one. After that, ask us about safely wiping it before you sell, donate, or recycle it.

How long does setup take?

It depends on how much data there is and how many updates the new computer needs. We’ll give you a realistic time estimate when you drop it off.

Do I need an appointment?

Walk-ins are welcome, and appointments are preferred so we can plan the time. Call (440) 525-5705.
