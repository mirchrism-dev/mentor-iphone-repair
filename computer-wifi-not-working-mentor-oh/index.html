Laptop or PC Won’t Connect to Wi-Fi?

When every other device in the house is online and your computer isn’t, the problem is usually the computer, not the internet. It might be a setting, a driver that broke after an update, or a Wi-Fi card that’s failing. Is It the Computer or the Internet?

  • If phones and TVs in the house are also offline, restart the modem and router first, or call your internet provider
  • If only the computer is offline, try a different network, like your phone’s hotspot. If that works, the issue may be how the computer and router get along
  • If the computer can’t see any networks at all, or the Wi-Fi option is missing, it’s more likely a driver or hardware problem

Things to Try First

1

Check airplane mode and the Wi-Fi switch

Make sure airplane mode is off and Wi-Fi is on. Some laptops also have a function key that turns wireless off.

2

Restart the computer, not just the lid

Closing the lid often only puts it to sleep. A full restart clears a stuck network connection.

3

Forget the network and reconnect

Remove the saved network, then join again and retype the password carefully. A router password change is a common cause.

4

Run the built-in troubleshooter

On Windows, the network troubleshooter and the Network reset option can fix broken settings. On a Mac, check Wi-Fi in System Settings and restart the router.

5

Install updates

After an update breaks Wi-Fi, a follow-up update or driver often fixes it. Plug into the router with a network cable if you need internet to download it.

Computer Wi-Fi Problem FAQs (Mentor, OH)

Why does my laptop say connected but no internet?

The laptop reached the router but isn’t getting online. Restart the router and computer first. If other devices work fine, it’s often a network setting, DNS, or leftover VPN software on the computer.

Why did my Wi-Fi stop working after a Windows update?

Updates sometimes install a driver that doesn’t play well with your Wi-Fi card. Rolling back the driver or installing the maker’s latest one usually fixes it.

My laptop can’t see any Wi-Fi networks. Is it broken?

Not necessarily. Check airplane mode and the wireless key first. If the Wi-Fi option is missing completely, the driver or the Wi-Fi card needs a look.

Can a Wi-Fi card be replaced?

In many laptops and desktops, yes. Some laptops have it built into the main board, and a small USB Wi-Fi adapter can be a cheaper fix. We’ll explain the options and price first.
