Try These First

1

Clean the top of the screen

Face ID uses sensors in the notch or Dynamic Island area. Wipe it with a soft cloth. Makeup, pocket lint, and fingerprints can all block it.

2

Check your case and screen protector

Some thick or poorly cut screen protectors and cases cover part of the sensor area. Take them off and try again.

3

Restart and update

Restart the iPhone, then check Settings > General > Software Update. Occasional Face ID glitches are cleared by a restart or an iOS update.

4

Check Face ID settings

In Settings > Face ID & Passcode, make sure the features you want are turned on. If you wear glasses or a mask often, try setting up an Alternate Appearance.

5

Reset Face ID and set it up again

Choose Reset Face ID and enroll your face again in good lighting. If setup fails partway or gives an error, that points toward hardware.

When It’s Probably Hardware

  • Face ID stopped right after a drop, a cracked screen, or water exposure
  • You see “Face ID is not available. Try setting up Face ID later.”
  • Setup won’t start or keeps saying to move the phone up or down no matter what
  • Face ID stopped working after a screen replacement somewhere else
  • Portrait mode selfies or Animoji also stopped working

Be aware that Apple pairs the Face ID sensors to each iPhone’s board, so a damaged Face ID sensor generally can’t be swapped for a new one by any independent shop. What we can do is find out whether the cause is something fixable, like a loose or damaged connection, a front camera issue, or water damage, and tell you plainly if it isn’t before you spend money.

Face ID FAQs (Mentor, OH)

Why did Face ID stop working after my screen was replaced?

A screen replacement involves disconnecting parts near the Face ID sensors. If one of those connections was damaged or not reseated properly, Face ID can stop working. We can check whether that’s what happened.

Can you replace the Face ID sensor?

Generally no, and neither can most independent shops, because Apple pairs those sensors to the phone. We’ll check for other causes that are fixable and be upfront if it isn’t.

Will a new screen fix Face ID?

Usually not on its own. The Face ID sensors are separate from the display. A new screen helps only if the old screen damage was blocking or affecting the sensor area, which we can check first.

Can I still use my iPhone without Face ID?

Yes. You can unlock with your passcode and use your passcode for Apple Pay and app sign-ins. It’s less convenient, but the phone works normally otherwise.
